# FH3X Dashboard 架构（Demo 生成规格）

## 1. 产品定位

单设备、本地 Modbus 户用储能控制台。首页只回答三件事：

1. 现在电从哪里来、去了哪里；
2. 电池和设备是否健康；
3. 用户下一步可以做什么。

视觉方向：复用 FH3X App 的住宅、光伏板、电池柜和图标资产；信息层级参考 Tesla Energy，但不复制 Tesla 的 Logo、Powerwall 外形或布局。

## 2. 应用壳层

### 桌面 / 2K / 4K

```text
HA 外层侧栏  |  FH3X 应用侧栏       |  页面内容区
             |  品牌 / 在线状态       |  页面标题 + 状态
             |  总览                 |  核心拓扑或业务内容
             |  光伏                 |  指标 / 图表 / 操作
             |  电池                 |
             |  负载                 |
             |  电网                 |
             |  运行策略             |
             |  告警中心             |
             |  设备诊断             |
             |  设置                 |
```

- HA 外层侧栏只负责进入“FH3X 能源中心”。
- FH3X 侧栏负责业务页面切换，不在页面内部再嵌套第三层导航。
- 2K/4K 页面内容最大宽度 1680–2400px；手机隐藏 FH3X 侧栏，改为顶部菜单。

### 移动端

```text
顶部：FH3X 标识                         设置
状态条：在线 / 数据延迟 / 离线
页面标题 + 一句话状态
一个主视觉（总览为能量流，详情页为核心指标）
指标卡纵向排列
底部或顶部抽屉：页面导航
```

## 3. 页面信息架构

| 路由 | 页面任务 | 首屏主内容 |
|---|---|---|
| `/fh3x` | 看懂当前能量状态 | 住宅中心动态能量流 |
| `/fh3x/solar` | 查看三路 MPPT | PV1/PV2/PV3 指标与趋势 |
| `/fh3x/battery` | 判断电池健康 | FH3X 柜体、SOC/SOH、温度、循环 |
| `/fh3x/load` | 了解家庭用电 | 当前负载、三相分布、趋势 |
| `/fh3x/grid` | 查看购电/馈电 | 并网功率、费用、R/S/T 相 |
| `/fh3x/strategy` | 设置运行目标 | EMS、计划 1–4、SOC 限值 |
| `/fh3x/alerts` | 处理问题 | 当前告警、历史事件、建议 |
| `/fh3x/diagnostics` | 工程排查 | PCS、BMS、模块、电芯、通信 |
| `/fh3x/settings` | 调整显示 | 主题、单位、刷新、动态效果 |

充电桩、发电机没有实体时不显示，不用 0 值占位。

## 4. 能源总览页面

### 桌面线框

```text
┌ 页面标题 ─────────────────────────────── 在线状态 ┐
│ 能源总览       “光伏正在供给家庭，多余电量进入电池” │
├───────────────────────────────────────────────────┤
│                                                   │
│     [光伏] ───────╲                 ╱────── [电网] │
│                    ╲   住宅模型   ╱               │
│     [电池] ────────╱               ╲────── [负载] │
│                                                   │
├──────────┬──────────┬──────────┬─────────────────┤
│ 今日光伏 │ 家庭负载 │ 电池 SOC │ 今日购电        │
├─────────────────────┬───────────────────────────┤
│ Impact：自给率/节省 │ 系统状态：PCS/BMS/通信    │
└─────────────────────┴───────────────────────────┘
```

### 节点规则

- 光伏：金色；显示总功率和 PV1/PV2/PV3。
- 电池：紫色；正值为放电，负值为充电。
- 电网：蓝色；正值为购电，负值为馈电。
- 家庭：青色；显示实时负载。
- 有功率：方向箭头、流速、颜色；零功率：静态灰线。
- 数据延迟：节点保留但显示“延迟”；离线：虚线/断开，不播放错误动画。
- 中心住宅必须使用正式 FH3X/Figma 模型，不使用黑色几何占位图。

## 5. 详情页统一模板

```text
页面标题 + 设备状态
核心 hero：正式设备模型 / 核心数值 / 一句话解释
三到四个实时指标卡
历史曲线：日 / 月 / 年 / 总计
工程详情：按能力显示，不支持的点位隐藏
```

### 电池页额外结构

```text
FH3X 柜体模型       SOC 72% / SOH 98%
                    当前充电/放电状态
                    SOC 轨道 + 温度 + 循环
模块列表：模块电压、温度、状态
电芯诊断：最高/最低电压、压差、告警
```

### 策略页控制卡

每个控制必须显示：当前值、允许范围、单位、预计影响、保存中、读回结果、失败原因。

- EMS 模式：枚举选择。
- 计划 1–4：启用、充电/放电、开始/结束时间、功率。
- SOC 限值：滑块或数字输入，显示保护影响。
- 所有写入二次确认，写入后立即读回。

## 6. 数据层契约

```ts
type EnergyFlowSnapshot = {
  timestamp: string
  pvPowerW: number
  loadPowerW: number
  gridPowerW: number
  gridImportW: number
  gridExportW: number
  batteryPowerW: number
  batteryChargeW: number
  batteryDischargeW: number
  batterySoc: number | null
  inverterState: string
  batteryState: string
  availability: 'online' | 'stale' | 'offline'
}
```

- BMS 地址：`1`。
- PCS 地址：`2`。
- 前端只读 HA 实体和调用 HA 服务，不直接访问 Modbus。
- 轮询周期按集成配置；超过 1.5 个周期为 `stale`，超过 3 个周期为 `offline`。
- 当前告警实体：`inverter_fault`、`inverter_warning`、`bms_protection`、`bms_alarm`、`active_issues`、故障码。

## 8. Demo 生成验收

- 先做总览页，再做电池页和策略页，三页通过后扩展其余页面。
- 必须同时生成浅色、深色、390px 手机、1440px 桌面四个画面。
- 不使用 Emoji、通用黑色 SVG、假 Tesla Logo 或未标注的假数据。
- 需要提供：页面截图、组件清单、颜色/字体令牌、交互状态、使用的正式 Figma 素材清单。
- Demo 只负责视觉和交互；HA 实体映射由现有集成负责。
